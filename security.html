Security

Your keys never reach Nexora

Every approval happens inside your wallet. Nexora only reads a public address and prepares transactions for you to review.

How Nexora is built

No seed phrase
Nexora never asks for a seed phrase or private key, on any page, for any reason.
Wallet signs
Each transaction opens in your wallet. You see the details and approve or reject.
Watch-only mode
A pasted address can look around but cannot sign anything.
Local settings
Privacy preferences stay in your browser.

Stay safe

  1. Check the address bar before you connect. Bookmark the real site.
  2. Reject any request for a seed phrase. Real support never asks for one.
  3. Read every transaction in your wallet before you approve it.
  4. Revoke old connections from inside your wallet's settings.
  5. Use a hardware wallet for larger balances.
This is a preview build and has not been independently audited. Treat it accordingly and start with small amounts.
