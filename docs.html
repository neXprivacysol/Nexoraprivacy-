Start in four steps

From first connection to a private balance. Concepts and the wallet detection code follow.

Quick start

  1. Open the Connect wallet page and approve the request in your wallet.
  2. Open Shield and move a small amount into your private balance.
  3. Check the Vault to confirm the balance and set your privacy controls.
  4. Use Send or Swap from the private balance.

Concepts

Shielded balance
Tokens held privately. Only your keys can show or spend them.
Note
The private record created when you shield. Spending a note moves value without naming you.
Route
One path a private payment takes. More routes hide more and settle slower.
Watch-only
A session with an address but no signing rights.

Wallet detection

Nexora lists wallets through Wallet Standard, so any compliant wallet appears without extra code.

const wallets = [];
const api = { register(...w) { wallets.push(...w); return () => {}; } };

window.addEventListener('wallet-standard:register-wallet',
  (e) => e.detail(api));
window.dispatchEvent(
  new CustomEvent('wallet-standard:app-ready', { detail: api }));

const solana = wallets.filter(w =>
  w.chains.some(c => c.startsWith('solana:')));

const { accounts } =
  await solana[0].features['standard:connect'].connect();
console.log(accounts[0].address);
